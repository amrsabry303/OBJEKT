# objekt — brand identity (V1, by dough, 2026)

Source: `Objekt Brand Guidelines V1.pdf` (54 pp, Downloads). This file replaces the earlier
working palette (Bone / Oxblood) used in the production book and workspace.

## Colour (sampled from the rendered palette pages; the PDF's own labels are placeholders that all read "AUTHORITY BLACK #000008")
| Role | Hex | Use |
|---|---|---|
| Warm Sand Beige | #E1D9CF | foundation / page ground |
| Deep Slate Navy | #25395A (logo vector fill #263A5A) | primary: logo, headings |
| Midnight Navy | #122948 | dark ground |
| Ochre | #9B6835 | accent (secondary) |
| Light grey | #CCCCCC | neutral ground |
| Black | #000000 | one-colour logo |

Logo pairings (p.26): slate on sand · sand-grey on slate · black on sand · grey on midnight · black on grey · sand on black.
Symbol and wordmark always share one colour. No shadows, effects, stretching, overlap, off-palette colours.

## Type
- Titles: **Galak Round** Regular, all caps for headlines. Italic (Galak Round Light Italic) for section labels like "03 // color palette".
- Body: **PP Mori** Extralight / Regular. 16/18 pt and 10/13 pt sample settings.
- Both are commercial fonts: not on Google Fonts, not in Slides. Stand-ins until licensed files are supplied.

## Logo
- Files here: `objekt-logo.svg` (slate), `objekt-logo-sand.svg`, `objekt-symbol.svg`, `objekt-logo.png`. Extracted as vectors from p.15.
- Clear space 1X (X = cap height of the wordmark) on all sides. Minimum: 25 mm print / 100 px web wide; below that use the symbol only.

## Voice
Confident, curious, crafted, plain. "Design worth noticing." Positioning: between function and expression.
Section labels use the form `03 // color palette`.
