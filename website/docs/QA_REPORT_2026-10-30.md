# QA report, 30 October 2026

Scope: the OBJEKT theme in the unpublished theme #189754769632, previewed through `shopify theme dev` at `127.0.0.1:9292` (local proxy of the password-protected store `hs1a1c-ut`), English layout, with right-to-left **simulated** by setting `dir="rtl"` and `lang="ar"` in the page (Arabic is not published, so no real Arabic output was seen). Browser: the in-app browser pane. Test data: three active `[TEST]` products, two `[TEST]` articles, one About page. Format below follows `docs/QA_CHECKLIST.md`: an item is "run" only if it was executed; "not run" means not executed.

## Result in one line
**No blocker found in what was run. Launch is not ready:** the checks that decide launch (checkout, deposit flow, real Arabic, real images, licences, content, founder approval) have not been run or are not yet possible.

## Checklist results (what was run)
**Visual**
- Brand colours: run. Static scan of every stylesheet, layout, snippet, section and settings file: the only hex values used are `#263A5A`, `#E2D9CF`, `#F7F5F1`, `#FCFBF9`, `#252525`, `#B4AEA7`, `#5F5A54` (the agreed palette). By the stylesheets, navy is the text and accent colour, and a background only in the collection feature section; page-by-page visual balance was not reviewed.
- No gradients, gold, shadows: run (static scan: no `gradient`, `box-shadow`, `text-shadow`, `drop-shadow` or `blur` anywhere). Fixed/sticky elements are only the header, the collection toolbar, the product and bag sticky bars and the sticky summaries.
- Placeholder imagery labelled: run. Every empty image slot is a sand panel labelled "Image to come"; nothing passes as product. Not run: the Creative Director audit of each template.
- Type scale and label consistency: partly run (minimum font size measured; QA-02 fixed). Not run as a design review.

**Responsive**
- No horizontal scroll: run, 0 overflow on home, collection, product at 351, 375, 768, 1024, 1440px; on bag, About, The Edit at 375 and 1440px; on story, search, 404, collections list at 375px.
- Tap targets 44px or more: run on the same pages and widths, 0 undersized interactive elements (skip link excluded; inline text links are exempt).
- Mobile menu, filter drawer, gallery, variant selector: run earlier in steps 1 to 4 (menu open/close/focus return, drawer open, live counts, variant switch). The gallery swipe with real images was not run (no images).

**Functional**
- Variant matrix: run on test data in steps 4 and filters: ready in stock, ready sold out, made to order, mixed product; price, label, delivery lines, button, `?variant=` URL. Per-variant image not run (no images).
- Made to order never shows stock count; deny policy: run (sold-out variant returned 422 from `/cart/add.js`). Overselling of a tracked ready variant with real stock not run.
- Cart: run (add, quantity, remove, mixed bag shows the ship together/separately choice, `delivery_preference` saved on the cart, line properties present). "Saved on the order" not run (no order was placed).
- Filters and sort: run (see filter section of the changelog). Smart collections Ready/Made to Order: not run (not created).
- Search: run (results, title, form, noindex). 404: run. Newsletter submit: not run (it would create a customer). Account: not run (customer accounts are hosted by Shopify; the link redirects, 302).

**Commerce**: nothing run. Checkout in test mode, EGP formatting at checkout, deposit flow, order data for fulfilment staff: all not run.

**Accessibility**
- Lighthouse accessibility: run, 100 on home, collection, product, bag, About, The Edit, story, search (mobile mode, local proxy). The 404 cannot be scored by Lighthouse (it rejects non-200 pages). Colour contrast of rendered pages: covered by that run.
- Keyboard-only pass with real focus, visible focus rings, screen reader pass (nav, gallery, variant live region): **not run**. The preview pane has no real focus, so focus events never fire. The skip link, headings (one H1 per page, no skipped levels), labels on all inputs, no duplicate ids and alt text on all images were checked by script.
- `prefers-reduced-motion`: the rule exists in `base.css` (static check); not emulated.

**Performance and SEO**
- Lighthouse performance 98 to 100 in the last run (earlier runs swung between 71 and 98 because of Shopify's own scripts and the local proxy); not valid as launch numbers (HTTP proxy, no real images, no licensed fonts). CrUX/INP: not run.
- Product and story JSON-LD valid JSON with expected types; titles, canonical, noindex rules checked on every template type. Google Rich Results test, sitemap, `hreflang`: not run.

**Theme editor**: partly run, static only. Every homepage section has presets; the editor UI itself (reorder, empty states, settings) was not opened.

**Launch**
- No active product carries `placeholder-data`, price 9999.00 or "[PLACEHOLDER]": run, passes (49 drafts, all tagged, 0 active). **But three active `[TEST]` products and two `[TEST]` articles must be deleted before launch.**
- PP Mori web licence: not held. Not run: rollback plan (Horizon stays the live theme, so the previous theme is still available; not written as a document). Founder launch approval: not given.
